# Nominal

Библиотека KiCad, в которой деталь выбирается по характеристикам, а не по артикулу магазина. Наличие ищется потом по уже заполненному BOM.

Пассивы разложены так: одна библиотека — это одна связка корпуса, типа, напряжения и допуска. Внутри только номиналы нужного ряда IEC 60063, и только до потолка этой связки. Футпринт уже стоит в символе. Поменять корпус значит взять другую библиотеку, а не оставить старый номинал в новом футпринте.

Примеры:

| Библиотека | Что можно поставить |
|---|---|
| `Nominal_C_0402_X7R_50V_10` | 0402, X7R, 50 В, ±10%, ряд E12, от 100 пФ до 100 нФ |
| `Nominal_C_0402_C0G_50V_5` | 0402, C0G (NP0), 50 В, ±5%, ряд E24, от 1 пФ до 1 нФ |
| `Nominal_R_0603_Thick_5` | 0603, толстая плёнка, ±5%, ряд E24, 1 Ом…10 МОм, плюс перемычка 0 Ом |
| `Nominal_R_0603_Thick_1` | та же плёнка, ±1%, ряд E96. Здесь есть 1,21 кОм и нет 1,2 кОм |
| `Nominal_R_0402_Thin_0p1` | 0402, тонкая плёнка, ±0,1%, ряд E192, 10 Ом…121 кОм |

Потолки ёмкости взяты из обычных рядов MLCC: 100 нФ в 0402 X7R на 50 В есть, 1 мкФ в этом же корпусе и напряжении нет. У X7R допуск каталога ±10%, поэтому ряд E12. У C0G процент начинается с 1 пФ, ряд E96 (±1%) — с 10 пФ. Толстая плёнка повторяет диапазон Yageo RC, тонкая — потолки Yageo RT. Полный список библиотек — в `passives/CATALOG.md`.

Символ `не_ставить` в каждой пассивной библиотеке — общий рисунок. На схему его не ставят.

Микросхемы и прочие свои УГО лежат отдельно:

| Библиотека | Что внутри |
|---|---|
| `Nominal_Power` | питание, силовые ключи, GND |
| `Nominal_MCU` | микроконтроллеры |
| `Nominal_Logic` | логика |
| `Nominal_RF` | ВЧ |
| `Nominal_Data` | АЦП и ЦАП |
| `Nominal_Sensor` | датчики, лазеры, фотоприёмники |
| `Nominal_Project` | символы конкретной платы |

Те же 12 698 пассивных строк лежат в `passives/nominal.sqlite`. Это источник для будущего поиска наличия по BOM. В выборе символа KiCad используется не эта база, а библиотеки выше: так не нужен ODBC-драйвер.

Старые схемы по-прежнему ссылаются на `oximeter_lib` и `mygost_lib`. Nominal их не заменяет.

Путь для KiCad задаётся переменной `NOMINAL_DIR`. На этой машине она уже прописана.
